# ai-pr-reviewer

A small React budget app paired with an AI code review agent that grades pull request diffs in CI.

- `apps/web` — expense tracker (React 19, Vite, TypeScript, Vitest)
- `packages/code-reviewer` — code review agent (work in progress)

## Getting started

```bash
npm ci
npm run dev     # http://localhost:5173
npm test
```

Requires Node 22+.
